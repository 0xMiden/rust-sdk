[BREAKING][arch][lib,store,cli] Moved hashing and Falcon signatures to Eidos, which changes commitments, account IDs, note IDs and nullifiers. The client requires a new store and a new keystore, and there is no migration from the old format ([#2813](https://github.com/0xMiden/rust-sdk/pull/2813)).
[BREAKING][rename][lib,cli] Renamed the Falcon scheme from Poseidon2 to Eidos: the `Falcon512Poseidon2` variants are `Falcon512Eidos`, `AuthSecretKey::new_falcon512_poseidon2` is `new_falcon512_eidos`, `RPO_FALCON_SCHEME_ID` is `FALCON512_EIDOS_SCHEME_ID`, `miden_client::crypto::rpo_falcon512` is `falcon512_eidos`, and the `--falcon512-poseidon2` CLI option is `--falcon512-eidos`. `miden_client::crypto` exports `Hasher` instead of `Rpo256` and `Poseidon2` ([#2813](https://github.com/0xMiden/rust-sdk/pull/2813)).
[BREAKING][type][lib] Removed `miden_client::crypto::FeltRng`, and `ClientRng` no longer has `draw_element` and `draw_word`. The `TransactionRequestBuilder` methods that take a random number generator take `&mut impl rand::Rng`. Import `miden_client::crypto::RngExt` and call `rng.random::<Word>()` to draw a word ([#2813](https://github.com/0xMiden/rust-sdk/pull/2813)).
