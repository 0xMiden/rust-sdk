[FEATURE][rpc] Added `NodeRpcClient::get_transaction_logs` and the `miden_client_grpc::v1::GetTransactionLogs` method, which fetch the logs of a committed transaction from the node's `GetTransactionLogs` endpoint. The result is a `TransactionLogsInfo`, with the logs of a public account or the logs commitment of a private account ([#2808](https://github.com/0xMiden/rust-sdk/pull/2808)).
[FEATURE][lib] Added `Client::get_transaction_logs`, which returns the stored logs of a tracked transaction. `miden_client::transaction` exports `TransactionLogs`, `TransactionLog`, `TransactionLogDetails`, `TransactionLogError`, `PublicTransactionLogs`, `LogTopic` and `TransactionLogsInfo` ([#2808](https://github.com/0xMiden/rust-sdk/pull/2808)).
[BREAKING][type][lib,store] Added `Store::get_transaction_logs`, which implementations of `Store` must implement. `SqliteStore` keeps the logs of each transaction that the client applies in the new `transaction_logs` table, with one row for each log. There is no migration for the table, so the client requires a new store ([#2808](https://github.com/0xMiden/rust-sdk/pull/2808)).
[BREAKING][behavior][lib,store,cli] Moved the protocol dependencies to revision `c0ecc47e`, which the node requires for transaction logs. `miden::standards::fee::pay_fee` takes the reference block number and the initial account nonce as inputs and returns two amounts, so a custom auth component that calls it must pass them. The multisig auth components pay the fee after the signature check. Their auth args are `[[bound_block_num, approval_expiration_block_num, max_fee, 0], SALT, CONVERSION_INFO]`, and the transaction summary binds the max fee, or a fee estimate if the max fee is zero. The fee note is not part of the summary that the approvers sign. An unsigned multisig execution does not reach the fee payment, so a fee that the account cannot pay fails only the signed execution. To sign a max fee, set `MultisigAuthArgs` with `MultisigAuthArgs::with_estimated_max_fee` through `TransactionRequestBuilder::auth_args` ([#2808](https://github.com/0xMiden/rust-sdk/pull/2808)).
[BREAKING][type][rpc] Added the `GetTransactionLogs` variant to `RpcEndpoint` and to `EndpointError`. Implementations of `NodeRpcClient` must implement `get_transaction_logs` ([#2808](https://github.com/0xMiden/rust-sdk/pull/2808)).
