[BREAKING][type][lib,store] Added the `StoreError::StaleUpdate` variant and the `StaleUpdate` enum, so exhaustive matches on `StoreError` must handle it. `SqliteStore` returns it instead of `StoreError::DatabaseError` when an account update is not based on the stored account state ([#2538](https://github.com/0xMiden/rust-sdk/pull/2538)).
[BREAKING][param][lib] `StateSyncUpdate::from_parts` takes `block_from`, the sync height that the update was built from, as its first argument. `Client::apply_state_sync` and `Client::apply_chain_updates` return `StaleUpdate::SyncHeightMismatch` if the store is at a different sync height ([#2538](https://github.com/0xMiden/rust-sdk/pull/2538)).
