[FEATURE][lib] Added `Client::prune_chain_anchors`, which deletes the stored MMR peaks at the past sync heights up to a block number ([#2740](https://github.com/0xMiden/rust-sdk/pull/2740)).
[BREAKING][param][lib,store] Added the required `Store::get_blockchain_peaks_by_block_num` method, which returns the MMR peaks at a past sync height. Added the required `Store::prune_chain_anchors` method, which deletes the peaks at the past sync heights up to a block number and keeps the genesis peaks and the current sync height peaks. Every out-of-tree `Store` implementation must provide them ([#2740](https://github.com/0xMiden/rust-sdk/pull/2740)).
[BREAKING][arch][store] The SQLite store keeps the MMR peaks at each past sync height in the new `chain_anchors` table, which replaces the `blockchain_checkpoint` table. The current sync height is the highest block number in the table. Requires a new client database ([#2740](https://github.com/0xMiden/rust-sdk/pull/2740)).
