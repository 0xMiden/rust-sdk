[BREAKING][param][lib] The `Store` methods for the client settings have no default bodies, so every out-of-tree implementation must provide them. These are the PSWAP lineage, note transport cursor and protocol configuration methods, and also `get_rpc_limits`, `set_rpc_limits`, `get_transaction_encryption_key`, `set_transaction_encryption_key` and `remove_transaction_encryption_key`. `Store::apply_state_sync` and `Store::insert_protocol_config` must store a protocol configuration with the same encoding ([#2700](https://github.com/0xMiden/rust-sdk/pull/2700)).
