[BREAKING][behavior][rpc] `GrpcClient` no longer sends the crate version in the `accept` header. Nodes from 0.18 ignore it because the RPC API is versioned by its protobuf package, so `AcceptHeaderError::NoSupportedMediaRange` now only means a genesis commitment mismatch ([#2762](https://github.com/0xMiden/rust-sdk/pull/2762)).
[BREAKING][removal][rpc] Removed `AcceptHeaderContext::client_version` ([#2762](https://github.com/0xMiden/rust-sdk/pull/2762)).
